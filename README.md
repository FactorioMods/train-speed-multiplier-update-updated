# Train Speed Multiplier: Updated

Multiplies locomotive top speed, braking force and engine power using the startup setting `Train-Speed-Multiplier`. Its default multiplier is 5.

This continuation retains the original setting and locomotive changes, with compatible Factorio 2.1 prototype handling.

Requires Factorio 2.1.24 or newer. The setting applies to the locomotive prototypes loaded by the game, including modded locomotives. A multiplier of 1 keeps the original prototype values.
